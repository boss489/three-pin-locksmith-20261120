# Art direction — 세 핀 열쇠공방

A tiny night workshop drafted like a locksmith's blueprint. Ink-navy field, grid drafting lines, brass rulings, oxidized teal for focus, coral for mechanical resistance. The lock and key are composed entirely from Godot vector drawing primitives: concentric dial, milled key teeth, three rising brass sliders, stepped guide marks, stamped panels, and eight-point cut-metal star. All graphics scale from a 390×760 logical composition; unused desktop area remains ink-dark, while 320px portrait shrinks the same composition without horizontal clipping.

Noto Sans KR is bundled in `assets/NotoSansKR.ttf` under `assets/OFL.txt`; the Web output carries `web/OFL.txt` as well. UI copy is Korean, with the compact English atelier mark used only as a decorative accent. Important state is not conveyed solely by color: highlighted slot, red exclamation, and explicit Korean first-mismatch message accompany the coral state. No answer height is disclosed by a failed test.

The three procedural PCM WAV motifs are generated by `audio_generate.py`: a short metal tap, dissonant resistance buzz, and ascending three-note opening chime. No external artwork or audio is used. The motion layer is the slowly rotating dial dots; pin heights visibly change in discrete steps.
